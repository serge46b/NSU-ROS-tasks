# ПР02. Типы сообщений

Дистрибутив: ROS 2 Jazzy. Тип позы взят из `ros2 topic type /turtle1/pose`.

## `/turtle1/cmd_vel` — `geometry_msgs/msg/Twist`

Команда скорости черепахи. Поля:

- `linear.x` — поступательная скорость вперёд вдоль оси тела, м/с. В опыте `1.0`.
- `linear.y`, `linear.z` — для turtlesim не используются (движение в плоскости).
- `angular.z` — угловая скорость вокруг вертикали, рад/с. Положительное значение поворачивает против часовой стрелки. В опыте `0.5`.
- `angular.x`, `angular.y` — для turtlesim не используются.

Одна публикация задаёт короткую команду: без новых сообщений симулятор обнуляет скорости.

## `/turtle1/pose` — `turtlesim/msg/Pose`

Состояние черепахи в окне симулятора. Поля, которые наблюдали в `ros2 topic echo --once`:

- `x`, `y` — положение в координатах окна;
- `theta` — курс, рад;
- `linear_velocity`, `angular_velocity` — фактические скорости после применения команды.

Имена `/cmd_vel` и `/turtle1/cmd_vel` — разные топики, даже если оба несут `Twist`. Подписчик turtlesim слушает только `/turtle1/cmd_vel`.
