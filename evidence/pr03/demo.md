# ПР03. Демонстрация patrol

Среда: WSL2, Ubuntu 24.04, ROS 2 Jazzy, `ROS_DOMAIN_ID=16`.
Тип позы: `turtlesim/msg/Pose`.

Симулятор: `ros2 launch turtle_bringup sim.launch.py`. Teleop не запускался.

## Роли init, spin, callback и Ctrl+C

`rclpy.init` создаёт контекст ROS в этом процессе: без него нет ноды и обмена.

`rclpy.spin` — исполнитель. Он ждёт события и сам вызывает callback. Подписка и
таймер только регистрируют работу; пока `spin` не крутится, сообщения не
разбираются и команда не публикуется.

Callback подписки `on_pose` только записывает последнее сообщение в
`latest_pose`. Он не считает Twist и не публикует команду. Callback таймера
`on_timer` раз в 0,1 с читает уже сохранённую позу и публикует Twist. До первой
позы команда нулевая; после — `linear.x = 0.5`, `angular.z = 0.3`.

`Ctrl+C` (SIGINT) прерывает `spin`. В Jazzy это приходит как
`ExternalShutdownException` либо `KeyboardInterrupt`. `main` ловит оба случая,
уничтожает ноду и вызывает `try_shutdown`. Нулевой Twist при остановке не
отправляется. turtlesim сам отбрасывает последнюю команду по своему таймауту,
поэтому процесс patrol может уже исчезнуть, а черепаха ещё чуть-чуть ехать.
Ждать остановки нужно по позе, а не по факту завершения процесса.

## Сбой: относительный cmd_vel

Команда: `ros2 run patrol patrol` без remap.

Издатель создан как относительное имя `cmd_vel`. У ноды `/patrol` пространство
имён `/`, поэтому полное имя — `/cmd_vel`. Симулятор подписан на
`/turtle1/cmd_vel`.

`ros2 topic info /cmd_vel --verbose`:

- Publisher count: 1, нода `patrol`
- Subscription count: 0

`ros2 topic info /turtle1/cmd_vel --verbose`:

- Publisher count: 0
- Subscription count: 1, нода `turtlesim`

Поза в начале и через 2 с совпала со стартовой, скорости нулевые:

```
x: 5.544444561004639
y: 5.544444561004639
theta: 0.0
linear_velocity: 0.0
angular_velocity: 0.0
```

Сообщения уходили в другой топик того же типа. Черепаха стояла.

## Исправление: remap

Команда:

```bash
ros2 run patrol patrol --ros-args -r cmd_vel:=/turtle1/cmd_vel
```

`ros2 node info /patrol` показывает подписчика `/turtle1/pose` и издателя
`/turtle1/cmd_vel`. Топик `/cmd_vel` в этом запуске отсутствует
(`Unknown topic '/cmd_vel'`).

`ros2 topic info /turtle1/cmd_vel --verbose`: издатель `patrol` и подписчик
`turtlesim`, тип `geometry_msgs/msg/Twist`.

Одно сообщение команды:

```
linear.x: 0.5
angular.z: 0.3
```

Поза во время движения:

```
x: 6.56543493270874
y: 8.52532958984375
theta: 2.4768147468566895
linear_velocity: 0.5
angular_velocity: 0.30000001192092896
```

Координаты ушли со старта, скорости совпали с командой.

## Частота за 10 с

```bash
timeout 10s ros2 topic hz /turtle1/cmd_vel
```

Команда завершилась по таймауту, код 124. За окно измерения средняя частота
держалась у 10 Гц (последнее окно: average rate 9.999, min 0.099 с, max 0.101 с,
54 сообщения). Таймер 0,1 с задаёт намерение 10 Гц; измеренный поток его
подтверждает, но период не является жёстким реальным временем.

## После Ctrl+C

Последняя поза ещё с ненулевыми скоростями была около `x=6.77`, `y=6.08`.
Сразу после SIGINT первая снятая поза уже с нулевыми скоростями, но в другой
точке: `x=7.098`, `y=6.618`. Черепаха успела сместиться после остановки ноды и
только потом остановилась. Повтор через 2 с дал ту же точку и нулевые скорости.
Остановка процесса не была отдельной командой торможения.
